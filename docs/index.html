Features

Everything you need, nothing you don't.

Machlif weighs in at under 1 MB and uses no background services, no cloud, no subscription.

⌨️

Any layout, detected automatically

Builds character maps at runtime from every non-Latin keyboard layout installed on your Mac — no hard-coded tables.

🎯

Configurable trigger

Double-tap Shift by default. Change it to Option, Command, Control — or record any modifier+key shortcut you like.

📋

Clipboard-safe

Your clipboard is snapshotted before conversion and silently restored 300 ms later. It's as if nothing happened.

⚡️

Instant & in-place

Works in any app — browsers, editors, terminals, chat apps. No copy-paste workflow, no app-switching needed.

🔒

Private by design

Runs entirely on-device. No network requests, no analytics, no account required. Ever.

🚀

Launch at login

One toggle in the menu and Machlif starts with macOS automatically, using SMAppService.

Install

Up and running in 60 seconds.

No Homebrew, no Xcode, no configuration files.

1

Download

Grab Machlif-1.2.dmg from the latest release.

2

Drag to Applications

Open the DMG and drag Machlif to your Applications folder.

3

Grant Accessibility

macOS will ask for Accessibility permission on first launch — this is how Machlif reads key events and pastes converted text. The מ icon will appear in your menu bar once permission is granted.

4

Start converting

Select any text in any app, double-tap ⇧ Shift, and watch it flip.
